# Diwali Glow — iPhone Wall Projection

A lightweight, self-contained animated Diwali projection web app. No external libraries, sign-in, or internet connection required once the files are on the device.

## Run it
1. Unzip `Diwali_Glow_iPhone_Project.zip`.
2. Open `index.html` in a browser to test it. For best iPhone use, host the folder on a simple HTTPS static host (for example, GitHub Pages) and open that HTTPS address in Safari. iOS local-file and fullscreen behavior can vary.
3. In Safari, tap Share → Add to Home Screen for an app-like icon.
4. Connect iPhone to a compatible projector (AirPlay or a suitable HDMI adapter), set projector input, turn iPhone brightness up, and select a scene.
5. Tap **Projection mode** to hide the controls. Tap the faint top-right Exit projection control to restore them.

## Scenes
- Diyas — flickering flame lamps and floating sparkles
- Rainbow Rangoli — rotating, glowing mandala
- Festival of Lights — looping colourful fireworks
- Floating Lanterns — drifting luminous lanterns
- Lotus Glow — rotating rainbow lotus
- Diwali Dream Mix — layered festive animations

## Notes
- Animations are drawn in real time on a canvas; they are GIF-like loops rather than separate `.gif` files.
- Fullscreen and landscape locking are subject to iOS Safari/device restrictions. If Safari does not allow true fullscreen, use Add to Home Screen and hide the controls.
- This is a small web app project, not a signed native iOS App Store app.
